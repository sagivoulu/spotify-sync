# Phase 5 — Test & Iterate

> Status: ⬜ Not started
> Goal: find where real people stumble *before* writing code, then fix and re-test.

## Planned methods

- **Usability testing** — give a user a *task* (not instructions), watch silently while
  they think aloud. The ~5-user rule (Nielsen) surfaces most issues; 3–5 WCS DJ friends
  + Sagiv with fresh eyes is enough.
- **Heuristic evaluation** — self-review against Nielsen's 10 usability heuristics
  (visibility of system status, match to real world, user control, error prevention,
  recognition over recall, etc.).
- Iterate on the prototype; loop until the core flows are smooth.

## Planned outputs

- List of usability issues found + fixes.
- A validated design ready to become the active UI PRD.
